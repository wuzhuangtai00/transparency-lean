## AI assistance and proof provenance

The Lean formalization, verification scripts, and accompanying documentation
were developed with substantial assistance from OpenAI Codex. This assistance
included translating the mathematical model into Lean, constructing proof
terms and supporting lemmas, and iterating using Lean's feedback.

The formalization includes a direct moment proof of the single-agent 9/8
bound, developed during this process, in place of the manuscript's two-state
reduction and calculus argument. It also includes an internal proof of the
welfare theorem cited in the manuscript's multi-action argument. The two proof
notes describe these differences. This package does not assert that the
alternative mathematical arguments are novel.

The proofs were checked using the pinned Lean and mathlib versions. Automated
verification establishes the formal conclusions from their formal assumptions;
it does not independently verify the translation from the manuscript, the
literature attribution, or the prose documentation. The validation records
describe automated checks and do not attest to independent human review.

## Validation records

[validation/checkpoint.json](validation/checkpoint.json) records the toolchain,
dependency revision, scope, source hashes, and audit count. The accompanying
logs were generated by [scripts/check.sh](scripts/check.sh). The GitHub workflow
runs that same command, with the project built from source and the pinned
mathlib cache used for dependencies.

The local validation environment required an executable-location compatibility
adapter because it does not expose `/proc/<pid>/exe`. The adapter supplies the
known toolchain location only when that lookup fails; it changes no proof,
kernel, or arithmetic code. Its source is retained at
[validation/host_compat/app-path-compat.cpp](validation/host_compat/app-path-compat.cpp).
It is not part of the package build or GitHub workflow, and ordinary Lean
installations do not need it. A successful hosted CI run provides an additional
reproduction on a standard runner.
